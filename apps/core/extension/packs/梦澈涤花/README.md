### 修改

#### 武将技能修改

# WB001-林雨霞
## 【流光乍裂》
1. 技力技（X）。出牌阶段限一次或当你受到伤害后，你可以将一张牌当作目标数为X的【杀】使用，若转化底牌为【杀】，则此【杀】无视距离限制。
2. 技力技（X）。出牌阶段限一次，或当你翻面后，你可以将一张牌当作目标数为X的【杀】使用，若转化底牌为【杀】，则此【杀】无视距离限制。

# RHHE008-絮雨
## 【漫雪覆塵》
1. 锁定技，当你处于濒死状态时，你回复体力至1点并摸一张牌，然后减1点体力上限；你的手牌上限为X（X为你已损失的体力值）。
2. 锁定技，当你进入濒死状态时，你回复体力至1点并摸一张牌，然后减1点体力上限；你的手牌上限为X（X为你已损失的体力值）。
