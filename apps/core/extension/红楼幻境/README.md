## 情思与花

- 基本牌与武器（equip1）手牌中的非花牌转化为独立基本牌【情思】，保留花色和点数，移除原牌名与原属性，不再作为原牌使用或打出。装备区内的武器，以及防具、坐骑、宝物和锦囊不在转化范围内；带花标记的武器仍保留原效果。转化后的情思离手不恢复原名。本次所说的“缘”沿用上一版统一的牌名“情思”。
- 【情思】有独立牌面和目标转移效果。成为其他角色使用牌的目标时，可以打出一张情思，将其中对自己的目标转给木石缘。保留原使用者和其他目标；木石缘须存活、合法且尚未成为该牌目标，忽略距离。情思没有主动出牌阶段效果，也可以被技能弃置。
- 不存在独立的“缘”卡牌。“木石”是角色关系标识；“花”是手牌标记。
- 葬花取得的原牌及复制牌均进入手牌并显示“花”。花牌不转化为情思，保留原牌名、花色、点数、属性和效果，可正常使用、打出或作为技能用牌。若葬花原本就名为情思的牌，其效果仍是情思。
- 花离手即失去花标记。每个角色回合结束后，仅将黛玉手中仍有花标记的牌置入弃牌堆并转为等量泪；已使用、打出、装备、转移或弃置的花不再计数。
- 第1、2、3…次葬花分别获得1、2、3…张花，取消不递增；次数于每个角色回合开始重置。复制牌只有进入弃牌堆时才销毁，不会在使用中或装备、判定时提前消失。

## 木石前缘

游戏开始必须选择一名角色为木石缘，不限性别，可以选择自己。木石缘的武将区域显示“木石”标识，查看标识可见与谁结缘；多个黛玉可以分别与同一角色结缘。

自己的回合开始时，可以选择一张可弃置的情思和一名不同于当前木石缘的角色。支付弃牌代价后更换关系；取消不弃牌、不更换。旧木石缘去除对应标识，新木石缘添加标识；其他黛玉的关系不受影响。

每次获得泪后，可选择自己或存活的木石缘摸等量牌，也可取消。选择自己时先摸牌，再弃置一张可弃置的情思；如果摸牌后仍没有可弃置的情思，则无牌可弃。木石缘死亡后，可以在自己的下个回合开始时重新指定。

## 潇湘妃子

木石缘与其他角色发生牌的获得转移，或成为其他角色红色用牌的目标时，可以获得泪。每个角色回合内实际发动依次获得1、2、3…枚。取消不递增；同次红色用牌只询问一次，普通从牌堆摸牌不计。

牌转移匹配同一移动过程中的实际失牌和得牌，包含批量分牌的子事件、交换手牌，以及从判定区或武将牌上取得的牌；批量转移及换手牌统一在完成时询问，避免子事件重复询问。红牌在目标调整完成后的 useCardToTargeted 时机判断，按使用者计算颜色；得泪提示显示本次触发原因。

木石缘以黛玉为用牌目标时仍须失泪，依次为1、2、3…枚，最低0；只有实际失泪才增加下次失泪量。得泪、失泪、葬花各自独立计数，每个角色回合开始重置。

## 绛珠归梦与遗愿

达到 max(8, 场上存活角色数 × 2) 枚泪时，完成本次得泪相关的可选摸牌及自摸弃情思结算，随后强制弃置全部手牌并直接死亡，不通过濒死求桃。人数下降时也检查阈值。

黛玉死亡前，可令当时存活的木石缘永久获得绛珠遗愿，也可取消；不是强制授予。

绛珠遗愿：受到伤害后，若仍存活，回复1点体力。每个角色回合一次，可代替其他角色承受一次伤害；拒绝不消耗次数。保留来源、数值和属性，一次伤害不重复转移。致命伤害仍须先通过濒死结算。

## 联机接入与更新

本项目托管联机通过 character/hlhj/index.js 加载与独立扩展相同的技能代码，房间武将包选项新增“红楼幻境”。创建房间时可与标准等包一同勾选；单独一名武将不足以满足选将池人数要求。

服务端继续禁止加载玩家上传的扩展代码。本体构建会将这份项目内确定的技能代码打入武将包；客户端构建携带武将图和情思牌图。公开的缘、泪和次数随选择状态及重连同步，其他技能的私有存储仍保持隔离。手牌转化只通知手牌拥有者，避免广播透露未公开手牌。

服务端和所有玩家客户端需更新到同一构建；源码更新后需重新构建并更新服务端运行资源，再重启服务。只导入 ZIP 或只重启旧服务端均不会更新托管武将包。

独立扩展的 connect 也已开启；传统联机要求参与者安装同一版本。当前修改尚未经过传统联机或托管联机测试。
