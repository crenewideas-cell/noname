# 十周年局内 UI

本工程重新编写的展示提供者。宿主要求：当前工程的 ESM 扩展、UI 工坊、可见头像标记及 `subscribePresentation` 公共接口。不是将来源扩展入口换名运行。

来源为子琪懒人包 1.11.5.1 终 APK 的 `assets/www/app/noname.zip` 中十周年 UI 1.3.1。作者名单和每个素材的来源成员、字节数及 SHA-256 在 SOURCE.json。源扩展的 LICENSE 原文保留；它不自动构成其中商业游戏美术、音效及第三方 Spine 库的另行授权。源 Spine 文件没有许可头，本工程没有补造授权声明。

## 使用与维护

UI 工坊中选择“局内 UI 方案 → 十周年局内 UI”，保存或应用。此操作保留大厅、模式选择、联机大厅和用户已有素材覆盖。动画、音效、动态立绘开关在方案下方，随套装保存、导出及联机外观数据传递。

日常清单生成运行 `node scripts/decade-inventory.mjs`；双包导出运行 `node --experimental-vm-modules scripts/export-decade.mjs`。两者只读取正式工程文件。一次性重新导入素材才使用 `python scripts/migrate-decade-media.py --source <APK>`，它按固定媒体路径及纯字面量动画元数据提取，不执行来源 JS。

## 展示职责

- presentation.js/CSS 装饰本体武将、双将、手牌、装备、判定、标记、确认取消、技能按钮、候选对话框、提示、菜单、翻面和结算表格；保留原节点、点击处理器、候选条件和可见性。
- layout.js 仅计算节点位置及缩放；无棋盘模式覆盖。
- animations.js 只订阅冻结的开局、卡牌、技能、判定、数值、阵亡和结果消息。攻击指示读取本体现有选中状态。缺资源、WebGL 错误、关闭和卸载不被引擎等待。
- portraits.js 只读取本体公开的头像标记。隐匿武将不启动素材请求；来源中存在的动态骨骼目前覆盖六名武将。其他武将保留本体合法静态立绘，不伪造动态资源。
- animation-renderer.js 复用当前手杀已提取的独立绘图类；vendor/spine.js 是来源绘图库的 ESM 导出适配。没有源技能、选择适配、AI、结算、联机或引擎覆盖程序。
- “结算”由本体提供结果和统计表；源十周年扩展自身未提供单独胜负结算资源。本层渲染结果标题及本体表格，未移入其它扩展的 MVP 评分业务。
