# 如真似幻新式扩展

2026-09-23 修复：正常加载不再叠加内置“正在准备界面…”文字；排位匹配轮盘在进入页面后播放，轮盘/入场动画使用当前 Spine 完成接口，异常时通过场景拥有的定时器续接本体选将。正常演出与停止渲染两种路径均已通过本地排位 2v2 浏览器验证。实际加载错误的恢复入口保留，规则仍由本体唯一实现。

原作：蒸、某个萌新、非凡欧德内里、文和，社区包版本 2.0.2。原包作者声明及第三方资源归属保持不变。

在大厅打开 UI 工坊，选择“如真似幻”，点击“一键使用所选套装”。大厅右下角“＋”可打开工坊、游戏设置、如真似幻设置和原版功能菜单；也可用 Ctrl+Shift+U 打开工坊。

大厅玩法按钮下方提供“人机对战”和“联机对战”。人机使用本地模式选择；联机接入本体的账号、房间与真实匹配界面，原有玩法的开战入口也遵循所选对局方式。联机对局沿用本体的独立启动流程。

`extension.js` 是当前工程的 ESM 扩展入口；`scenes.js` 保留原大厅、模式、招募、天梯与武将浏览逻辑，接入当前 `OnloadSplash` 生命周期。没有复用旧 `lib.init.onload`、登录跳转或整套游戏启动器。UI 工坊的 `home.runtime` 只引用本工程内置的程序，不执行导入清单中的任意代码。

画布按窗口宽高比确定逻辑尺寸，按钮图像等比缩放，背景单独等比铺满。等比例缩放只调整画布；窗口宽高比变化时重新布局，并恢复已打开的大厅、模式、天梯、武将、招募或个人页面。加载背景覆盖整个视口；已选套装的启动外观缓存仅用于第一帧显示，实际配置仍由游戏数据库决定。

武将页只建立武将索引，可见行及相邻行才创建卡牌和请求原画，最多并行加载四张原画，不再把所有武将加入启动加载队列。原画通过本体 `setBackground` 规则解析，支持扩展路径、别名、皮肤、本地数据库与默认图像；武将包标题作为纯文本显示。大厅音频由独立的音频对象管理；切换模式时停止本大厅的音频并释放动画、定时器、加载器、画布和样式，避免已销毁音频对象的解码回调访问空上下文。

武将原画按卡框内部尺寸等比铺满并裁切，不沿用旧版的固定拉伸高度。滚动视口使用全部筛选结果的总高度，可一直滚动到末尾；屏幕外的卡牌继续保持按需创建。

UI 工坊导出含完整扩展资源；导入后可选择或混搭交互大厅。交互大厅内部的动画按钮、模式页面是同一个功能组件，其余卡牌、对局样式与指示线仍可独立搭配。

## 原包的资源边界

原包中的部分按钮本来就是“功能暂未开启”提示，这些按钮保留提示，不会启动未提供的网络服务。

梦之回廊需要的十周年 UI 动态皮肤、吕玲绮“战场绝版”等第三方骨骼不在提供的原包中。未提供的个人页骨骼使用原有静态回退；回廊打开前检查依赖并说明缺失，避免读取不存在的骨骼导致异常。缺失的原画使用本体默认头像，代码不会伪造原作素材。

`scripts/migrate-rzsh.mjs` 可从原始 temp 目录重新生成素材和迁移后的场景模块；手写的入口、桥接模块及现代样式不被覆盖。最后一轮修改按用户要求交由用户验收，未再运行测试。
