2026-09-23 修复：局内仅保留一层出牌提示；右上角采用原包 SSCD 展开菜单，复用本体导航及设置/托管控件。排位匹配重新播放轮盘，使用当前 Spine 完成接口，并在动画异常时续接本体选将。桌面与窄横屏、皮肤切换、排位 2v2 开局已通过浏览器验证。详见 `docs/ui-display-and-ranked-start-fixes-2026-09-23.md`；需要配合更新后的宿主入口。

当前套装保留原登录、大厅、布局、按钮、立绘及动画素材；游戏规则和操作由本体负责。源码状态和待办以 [UI 核心统一说明](../../../../../docs/ui-core-unification.md) 为准，本文不是运行验收报告。

- `extension.js` 注册大厅和展示生命周期；`native-runtime.js` 创建场景草稿和资源管理器。
- `native/lobby.js` 只包含大厅场景。进入对局提交本体支持的模式选项；不执行旧选将、技能、装备、AI、伤害或胜负程序。
- `native/presentation.js` 装饰本体节点；`native/animations.js` 使用本体单向快照及独立绘图类。选项、事件及继续游戏的控制权不传给动画。
- `original/` 保留外观素材和仍使用的 PIXI、GSAP、Spine 绘图库。旧扩展入口、九模块程序、选将覆盖和兼容加载器已经删除，不能重新接回执行。
- 可发布程序由本体的 `ui/workshop/providerFiles.js` 明确列出，工坊导出、联机资源复制、Electron 和 Android 资源收集共享此边界。`files.json` 是资源索引，不是任意脚本执行许可。
- 套装配置保存在 `ui_workshop_shousha_settings`；本体模式、昵称和启用武将包通过明确宿主动作修改。场景副本不保留本体原型或回调。

开发者从外部参考工程重新迁移时使用 `scripts/migrate-shousha-native.mjs --source=<resources/app>`；生成器只接收外部源文本并输出大厅、绘图代码和字面量素材数据，不再把旧业务模块写入套装。日常构建使用已保存的展示源码，不需要参考工程。旧 `migrate-shousha.mjs` 已删除。

当前目录的废弃 `assets/`、`spine/` 和旧素材 ZIP 尚有物理残留：清理被自动审批拦截。它们已排除在当前清单和新打包入口之外，不能据此宣称磁盘已清空。原始素材的可用性和视觉完整性仍由用户验收。

本轮未运行测试、生成器、静态检查、游戏、构建或打包。现有安装包和历史报告不代表本轮源码状态；需重新构建本体、独立联机客户端及对应桌面/Android 客户端。
