# 绯雪安装

来源：`temp/扩展武将/绯雪.zip`，原 ZIP 保留。

安装目录：`apps/core/extension/characters/绯雪·动态/`。刷新或重启当前项目，在“扩展 → 独立武将 → 绯雪·动态”中查看。首次登记默认启用，之后保留用户手动开关。

保留常世身、预求身两个武将定义、四组技能动画与音频、三张立绘及原作者信息。沿用原包的禁止随机 AI 选取标记，可手动选择。

移除未被武将使用的“测试6”技能及对应翻译。旧入口改为模块导出；动画样式独立加载，替换缺失的 `game.createCss`；见心以原有存储状态控制解锁，不再调用缺失的 `shixiaoSkill` / `unshixiaoSkill`；归刃采用引擎原生选层菜单，支持取消，不依赖外部界面控件。

安装登记包含来源 ZIP 的 SHA-256 和全部 14 个文件的哈希。浏览器验证命令：

```powershell
node scripts/feixue-import.browser.mjs
```

默认使用 `http://127.0.0.1:18081`，可通过 `NONAME_UI_TEST_ORIGIN` 指定运行中的开发地址。5 项检查通过：默认登记和独立武将分类、双形态及技能编译、头像与动画音频加载、挽雪与见心切换、霜天与归刃选层及结算。页面错误为零。技能步骤使用真实引擎编译器与玩家对象，跳过动画等待和声音播放；归刃伤害调用按参数检查，未验收完整对局或联机同步。

本次安装到当前项目源码，未重新生成 EXE 或 APK。
