# 局内攻击指示线

UI 工坊中的选项名称为 **手杀指示线**。内部继续接受 `Liuli`，兼容此前已保存的搭配，无需重新建套装。

原先错误地使用了 `十周年UI/effect.js` 的浅粉细直线。本次改用参考工程 `祖安武将/extension.js` 默认官阶路线中本地玩家使用的金色 `yulongLineXy/line.png`，沿用该路线的 60px 高度和 1400ms 伸缩/淡出。原图与迁入的 PNG 哈希一致，没有重新设计素材。

| 配置值 | 工坊名称 | 素材 |
| --- | --- | --- |
| `Liuli` | 手杀指示线 | 原版金色玉龙，60px 高 |
| `ZipYulong` | 玉龙（指示线扩展） | ZIP 玉龙，50px 高 |
| `ZipJingdian` | 经典（指示线扩展） | ZIP 经典 |
| `ZipBaoji` | 暴击（指示线扩展） | ZIP 暴击 |

手杀展示层的旧浅粉 SVG 线已移除；选择 `default` 的旧手杀搭配也改走金色指示线。其他本体套装的默认指示线保持原设置。拖拽选择仍保留本体节点复用逻辑。低性能或关闭特效时保留原本的降级行为。

运行只依赖工程内的 `apps/core/image/pointer/migrated/`，不依赖 temp。来源与哈希见该目录的 `SOURCE.json`。不安装旧扩展的规则钩子、官阶系统或 eval；暴击素材为独立可选样式。ZIP 未提供的帧序列不补造、不请求。

上一轮只验证了浅粉线能渲染，不能作为目标效果迁移正确的证据。用户本次明确要求不测试，已停止后续测试；不以旧测试结果宣称本次画面已验证。
