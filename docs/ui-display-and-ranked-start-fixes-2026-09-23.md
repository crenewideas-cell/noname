# 2026-09-23：提示重叠、手杀菜单、加载提示与排位匹配修复

本轮按用户四项反馈修复，不扩大为全套 UI 的零遗漏验收。

## 实现

- 手杀局内挂载时通过宿主已有的 `suspendSelectionGuide` 暂停额外选择引导层，保留实际出牌/技能提示和确认、取消按钮。卸载皮肤释放暂停所有权，内置引导可正常恢复。
- 右上角菜单使用原包 `SSCD/yemian.png` 及设置、退出、逃跑、投降、托管图标。继续复用宿主导航对话框及其继续、重开、返回、退出处理；设置/托管/投降转发到原有控件。未提供投降的阶段显示禁用按钮。等待原导航关闭并释放暂停之后再触发设置，防止相互覆盖暂停状态。
- 如真似幻正常加载时不再附加“正在准备界面…”等文字；加载画面由原场景展示。实际加载失败仍保留原有错误及恢复入口。
- 两套大厅的匹配轮盘改为进入匹配页时重新播放；轮盘与最后一个官阶入场动画均使用当前 Spine 的 `TrackEntry.listener.complete`。正常动画完成后调用既有启动桥接。手杀排位的展示槽为四个头像加中间 VS，核心仍按原对抗 2v2 模式创建四位玩家。
- 增加随场景释放的 20 秒续接定时器，动画停滞也可进入选将。正常演出先走完成回调；如真似幻返回其他视图后不触发续接。源码生成脚本同步保留修复。

以上变更未引入游戏规则、技能、选将或对局事件的第二份实现。没有启用原包排位统计、扣星和规则脚本。
