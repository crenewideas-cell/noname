## 名将杀

用户要求撤掉“名将杀·0.0.3”子包，直接把武将加入原“名将杀”。现有三个菜单条目仍为“名将杀”“名将新修”“名将旧改”。新增武将按原分类并入秦扫六合、合纵连横、三国云起、晋洛兴替、楚汉之争、汉武盛世等栏目。

原包由高山流水制作，与原整合版存在同 ID、不同实现。新增武将及技能继续保留内部独立标识，防止覆盖原整合版，也保留上一轮导入后保存的武将选择或禁用记录。这里只合并包归属，不删除新增武将变体或替换原技能。

代码位于 `apps/core/extension/packs/名将杀/main/imported-characters.js`，由 `main/incremental.js` 在原包登记完成后合并到 `lib.imported.character.mjs` 和 `lib.imported.card.mjs`。不向外层扩展的 `package.character/card/skill` 写入独立包。

素材已移至 `assets/incremental/`，原 `supplements/0.0.3/` 目录已撤除。原始 ZIP、作者和版本来源保留在导入记录中。仅保留立绘、士族牌堆与按钮等选项，统一标为“增量武将”；旧版独立子包开关不再参与加载。旧子包的武将和卡牌包选择记录在初始化时移除，原 `mjs` 选择及扩展总开关保持不变。

阵亡音频接入本项目元数据；立绘选项使用游戏存档及明确的素材列表；原包缺失的玉剑图片使用引擎文字卡牌。
