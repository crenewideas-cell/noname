# 大厅周边界面统一（2026-09-27）

以已经实现的大厅设置为模板 0，提取共用样式，保留模板 0 的显示效果。参考图用于页面内容组织，按钮、标题栏、面板、输入控件和开关均采用模板 0 的元素，不另建按钮素材。

## 实现范围

- 联机登录、注册、房间列表、创建房间、房间码加入、房间等待区、武将池和开局规则编辑、社交弹窗及入席/重连提示。
- 皮肤管理、静态套装、动态资源库、分配清单及导入/转移/动态预览对话框。
- 手杀标准 UI 界面设置。
- UI 工坊的工具栏、套装库、编辑区域、预览周边控件和状态提示。

公共视觉定义在 `apps/core/layout/default/lobby-surface.css`。大厅设置、皮肤管理和联机 CSS 导入这份文件；工坊的 Shadow DOM 注入同一份样式。普通、选中、按下、悬停、禁用和键盘焦点状态由公共规则维护。

各页面保留自己的业务与内容布局。游戏主题、武将图片、对局素材和工坊的实际游戏预览内容继续由原来的套装控制。工坊的自定义外观规则排除这些公共管理界面，避免切换套装后再次覆盖统一元素。

工坊和手杀设置使用原生模态对话框，避免游戏对 body 的缩放影响窗口尺寸。关闭、Esc、草稿放弃确认与原有保存操作继续使用已有逻辑。

## 整页滚动

根据后续要求，各区域按照内容自然展开，只由当前页面最外层容器上下滚动：

- 工坊：工具栏、套装库、编辑区、预览区和状态栏随整个工坊一起滚动。
- 皮肤管理：武将列表、皮肤详情、资源包列表、导入清单和动态分配清单取消内部限高与独立滚动。
- 手杀设置：设置内容自然撑开，由整个设置画面滚动。
- 联机：武将池与聊天记录自然展开，由大厅或当前对话框滚动。

桌面、矮窗口和竖屏均使用上述方式；未用隐藏滚动条的方式裁掉内容。模板 0 依照最初要求保留原有布局与滚动方式。文本编辑控件和实际游戏预览保持其自身输入/展示语义。

## 排版与可用性复查

- 登录按用户参考图恢复战场背景、左侧人物画面、右侧登录表单、独立连接状态条。注册与找回密码作为文本入口；主按钮继续使用模板 0 素材。图片不包含控件和文字，布局与输入仍为真实页面元素。
- 房间等待区将席位、对局设置、房间消息明确分组；五人席位在宽屏一排展示。规则用名称和值呈现，编辑与详细说明按需展开。聊天记录与输入行同宽，发送、查找按钮不再被挤成竖排。
- 房间列表、快速匹配和武将池将详细规则收入说明区，保留关键信息与操作入口。
- 工坊颜色改为预设与取色器，字号、圆角、间距、阴影、不透明度提供明确选择；旧有自定义值保留，选择“沿用原样式”删除对应覆盖。部件列表改为可展开搭配清单；素材说明精简，格式说明按需查看。
- 皮肤列表增加武将缩略图；套装保留/归档说明收起。导入分配与原画移动选择武将名称，不再要求用户猜测并输入武将 ID。动态库减少重复导语，保留选择、预览和分配步骤。

新增控件验证覆盖颜色、字号、透明度切换与保存恢复，以及导入选择、跳过校验。联机测试增加 1800×875 参考构图和 600×900 窄屏登录，检查标题栏透明、返回入口位置、人物素材与标题层级。自动检查之外逐张检查实际截图，发现旧样式覆盖时继续修正。

## 房间参考图修订

按用户新增房间参考图，将已入房状态独立为 `online-room-scene`：月夜宫阙背景、共用描金纸张面板、完整玩家席位区域、左右并列规则表与消息区、底部好友区。五人一行、八人两行，窄屏自然换行；规则表改为一行一项，聊天区与设置区对齐。关联的武将池、规则编辑及邀请对话框沿用房间表面元素。实际搜索仍使用玩家码，规则名称与数值仍来自运行状态，不照搬参考图的示意文字。返回大厅与退出房间复用既有离房逻辑，创建中的禁用保护保留。

新增资源、生成方式与提示词见 `apps/core/image/lobby/SOURCE.md`。房间布局及绘制集中于 `room-scene.css` 与 `RoomIcon.vue`，按钮继续复用模板 0。浏览器验证新增参考尺寸 1227×1282、600×900、八人席位及长消息；截图为实际 Vue 页面。

## 房间列表与房内场景统一、展开背景修复

登录后的房间列表也启用同一个 `online-room-scene`，复用月夜背景、页头、纸张与描金边框。列表、创建入口、快速匹配、好友及创建／加入弹窗使用相同表面定义；空列表与有房间卡片两种状态均保留原有操作。按钮仍由模板 0 的公共规则绘制。

原纸纹使用 `100% 100%` 拉满面板，展开设置会纵向变形；弹窗的 `cover` 同样会因高度变化改变图案大小。现将装饰分离到不参与布局的底部绘制层，以宽度等比缩放，顶部渐隐衔接纸色。面板增高只移动底部装饰，不拉伸图案；描金边框继续使用九宫格切片。外层夜景按视口固定，设置、列表和聊天仍使用整页滚动。

浏览器回归增加：列表／创建／匹配／好友／加入面板共用素材，匹配规则展开，房间三组设置全部展开与收起后的宽度和纸纹比例检查，以及桌面与 600×900 创建、加入、空列表和房间卡片截图。测试使用内存模拟状态，不创建真实房间。
