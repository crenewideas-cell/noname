# 扩展卡牌审计与修复（2026-09-27）

## 名将杀是否完整

工程内已包含名将杀卡牌。本次以本地扩展 `0.0.28-260321` 与已导入的 `名将杀0.0.3.zip` 增量为基准，实际加载得到 **88 个卡牌定义：85 个基础定义 + 3 个增量定义**，全部出现在名将杀卡包目录中。

默认牌堆有 **41 条花色、点数、牌名记录**。卡牌定义数、不同牌名数、实际牌堆张数是不同口径；衍生牌和技能产生的牌不会全部塞进默认牌堆。这次没有把 88 个定义强行加入牌堆。

结论只适用于工程内上述来源。没有拿官方最新完整卡表逐项比对，不能据此宣称包含名将杀所有历史、最新官方卡牌或玩法。

## 大厅为什么找不到

卡包由父扩展的加载过程注册。原先父扩展未加载时，卡牌菜单只枚举运行时已注册卡包，因此目录完全没有“名将杀”；这不能说明工程没有卡牌文件。菜单创建在注册之前时，也缺少统一补刷。

现在已安装但尚未加载的名将杀、华夏风云、星之梦、极略七杀、怒焰三国有来源说明和“前往扩展设置”入口。开启父扩展后，用实际卡包替换提示项，并刷新目录，避免重复菜单。此提示不会执行已关闭扩展。

使用顺序：大厅设置 → 扩展 → 开启“名将杀”；再到卡牌 → 名将杀检查卡包开关。父扩展开关控制代码加载，卡包开关控制牌堆启用。
