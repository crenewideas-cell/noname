# R13：局内点击、指示线、自动互动与联机死亡身份

日期：2026-09-27。接续 R12，公共动态播放器仍为 `76a45a82cbc187aa950c`。本轮修改宿主界面和身份模式，不重新复制皮肤包运行代码。

## 修复

- **装备区滚动条和点击遮挡**：核心 `.hidden` 只隐藏空装备槽的内容，旧紧凑布局仍为每个空槽保留 22px 行高，多个空槽把装备容器撑到头像中间。本轮让隐藏行退出布局，空容器不拦截指针，实际装备标签仍可点击；超过六行的实际装备仍可滚动，但不绘制头像右侧滚动条。改动同时覆盖手杀和十周年紧凑装备展示，不改变装备节点、归属或选择逻辑。
- **指示线偏离**：原来混用了未缩放的 `getLeft()/offsetWidth` 与手杀座位的 CSS zoom。统一从角色实际屏幕矩形换算到 arena/chess 容器坐标，计入容器缩放、边框、滚动。四种金色线的旋转轴都对准自身半高，不再额外延长 2px。送花、砸蛋、拖鞋使用同一坐标换算，装饰层不拦截点击。
- **联机身份模式死亡仍显示“猜”**：死亡广播已经携带真实身份，但回调错误地使用客户端旧的 `player.identity`。现先应用广播值，再公开徽标；死亡大字改为可更新。重连状态包含公开标记，已死亡角色及已公开身份刷新显示，存活的隐藏身份仍保持隐藏。特殊身份和反转朝向保留。
- **自动互动**：取消开局全员送礼、手牌多就庆祝和连续十连发。只根据完成后的公开效果选一名角色回应。

## 新互动规则

| 有效表现 | 计分与反馈 |
| --- | --- |
| 对敌伤害 | 每点 2 分；本方表现送花，敌方表现回应鸡蛋，强效果末尾改拖鞋 |
| 资助牌 | 明确赠予或能归因的支援，每张 1 分；不会把从队友处夺牌当成对方资助 |
| 治疗 / 护甲 | 每点有效收益 2 分；自己给自己不互送 |
| 救援 | 有救援来源且恢复到正体力时额外 3 分 |
| 帮队友解除翻面 | 3 分 |
| 击杀敌人 | 5 分 |
| 明显友方伤害 | 鸡蛋或拖鞋；识别到卖血收益标签时不判为失误 |

650ms 内的效果合并，每 2 分对应一个表情，单次上限 4 个。每次只选一个回应者，优先受益者及本方玩家；全局至少间隔 3 秒，同一发送者至少 6 秒，同一双方至少 12 秒。自动礼物不会再引发自动回礼。结束、关闭展示时取消待发任务，新一局清空冷却。

自动行为仍限本地离线的人机互动；不冒充联机真人，也不替代其他受控角色发言。手杀设置里的“自动送花与砸蛋”和“表情自动回礼”继续有效。任意扩展的自定义增益、无来源的资源变化不自动猜测归因。
