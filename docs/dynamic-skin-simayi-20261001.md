## 复验

运行 `node scripts/dynamic-simayi-browser.mjs` 可在独立静态服务中检查司马懿 10 张皮肤。
设置 `SKIN_SWEEP=1` 可生成双尺寸、多时间点截图；`SKIN_RUNTIME` 可指定待比较的共享版本目录；`SKIN_CASES` 接受皮肤 ID 的 JSON 数组。
`scripts/dynamic-simayi-ui.mjs` 对本地开发服务 `127.0.0.1:18084` 执行真实游戏入口的出场和交互检查，`SKIN_CASES` 接受 `[皮肤ID,武将名]` 数组。
