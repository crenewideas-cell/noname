# 小立绘缩放清晰度修复

局内头像与千幻手杀换肤卡片都直接使用原画。怒焰董翓资源为 1088×1445，之前由浏览器直接缩到约 100×180 像素，细密发饰和衣服纹理产生明显锯齿和噪点。

核心 setPortraitBackground 保留原有同步设置背景和回退图层，在可见的小头像上按实际显示尺寸及 devicePixelRatio 生成高质量缩小版本。优先使用 createImageBitmap 的 high 重采样，不支持时逐级缩小；PNG 缓存最多 32 份、源图片缓存最多 8 份。大立绘、GIF、动态画布、自定义裁切和透明素材保留原显示方式。没有修改素材文件、布局或控件。

ResizeObserver 及窗口缩放更新采样尺寸；异步结果校验节点与当前来源，避免换肤后旧图覆盖。隐藏节点不生成缩小版本，删除节点停止观察。处理失败保留原背景。

验收：

- node scripts/portrait-quality-browser.mjs：手杀、手杀 DPR=2、十周年。使用同一张董翓原画，比较局内头像、换肤卡片的前后截图，并确认大图仍使用原图；覆盖缩放、还原大尺寸、快速切换来源、缺图回退、移除和隐藏节点、旧浏览器逐级缩小分支。
- node scripts/qianhuan-menu-browser.mjs：原菜单三组 21 项交互回归通过，确保换肤、还原、主副将、右键/长按入口和暂停恢复没有回归。
- 图片及报告：output/portrait-quality/，菜单回归：output/qianhuan-menu/report.json。

小图受到实际显示像素数量限制；本修复消除明显的缩小采样噪点，不会增加原画本身的细节。
