## 启用与验收

### 选将人数异常修复

自由选将默认可以使用“最近”筛选，旧分页界面切换武将包时仍保留该条件，人数因而可能显示为 1 或 2。本次修复为切换武将包时清除最近／收藏、首字母、势力和搜索条件，并在再次应用筛选时显示当前条件；限定单包打开时不应用“最近”默认值。

极略原入口没有把五个内部子包加入 `lib.config.characters`，主程序因此能登记资料但跳过可选武将。现已在首次启用或旧安装升级时补登记一次，并补齐清晰的子包标签；以后手动关闭子包会保留。对局测试仍由用户进行。

同时更正了首轮静态统计只计入怒焰基础分表的遗漏，补记条件导入的界限突破和附加形态；它们的源码此前已完整导入。开发检查面板现按真实内部包名读取三个扩展，并按怒焰设置计算预期定义数，不再把内部包误计成零个。

重启开发服务或游戏后，在“扩展 → 武将扩展包”中查看。名将杀保留已有存档开关；新导入的极略、梦澈涤花、怒焰三国首次登记默认关闭，启用后按游戏提示重启。极略的五个子包在武将菜单中归为“极略”。已生成的 EXE/APK 不会随源码自动更新，需另行重新构建。
