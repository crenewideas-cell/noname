# 千幻聆音原版安装与兼容适配

2026-09-24：阶段一、二完成。以下四个浏览器场景均通过，未发现页面运行异常；动态渲染与发布平台验证留在后续阶段。

## 路线与来源

按用户最终决定，安装原版千幻聆音并适配当前核心，废弃自行重写皮肤页面的方案。旧衣橱不恢复。入口覆盖手杀标准 UI、如真似幻大厅、人物资料和局内主副将；界面使用原版手杀主题。

程序唯一来源：`temp/千幻聆音.zip`，版本 **4.16.1.11**，SHA-256 `7cb300cae9ef8e3ca83961eec1ef97ab62b112e5d50effdfe294b7c735e90e80`。原始 ZIP 使用 GBK 文件名，包含 1159 个文件，安装于 `apps/core/extension/ui/千幻聆音/`。保留 LICENSE、作者与全部原文件哈希；SOURCE.json 单独记录适配文件和新增文件。

ZIP 不包含完整 sanguoskin/sanguoaudio 图库，复用当前项目 `apps/core/extension/ui/手杀标准UI/original/千幻聆音/` 内已交付资源。程序不再依赖 temp 中的旧版千幻；resource-sharing.json 仅保留这批既有资源的显式武将、技能语音共享关系，新 ZIP 自带声明优先。两者是程序与素材依赖，不要求启用手杀标准 UI 扩展的旧业务。

## 阶段一：原版安装与入口（已实现）

- 原版 ESM 程序、主题、资源加入 extension-catalog 与 organized-extensions；首次注册默认启用，保留用户之后的禁用选择。
- 删除此前自制页面 view/model/catalog、旧迁移脚本和对应测试。核心只保留调用原版页面的入口桥接，不再维护第二套皮肤页面。
- 大厅皮肤按钮、人物资料按钮调用原版 qhly_open_new。附加武将搜索选择器；连续切换武将保持同一会话，方便大厅清理窗口。
- 保留原版大立绘、技能/选项/简介、皮肤列表与点击换肤。页面按视口和核心缩放适配，关闭时撤销监听，恢复进入前的暂停状态。
- 旧版将功能延后到局内加载的配置不再导致大厅按钮失效：precontent 等待主题脚本后仅初始化一次。

## 阶段二：当前核心兼容（已实现，验收见下）

- compat.js 桥接原版换肤回调与当前核心皮肤存档，刷新 DOM 主副将头像和两套大厅的 PIXI 头像。经典还原清理对应选择；已有核心存档中的共享图库路径可迁入原版配置。
- 保留核心 setBackground/setBackgroundImage 与隐藏武将处理；原版经典皮肤缩略图显式使用默认立绘。
- filesystem.js/file-access.js 仅在千幻内部适配文件发现。优先读取实际目录，支持新增/删除素材；文件服务缺失、失败或超时降级到随包资源索引，回调只完成一次。
- metadata.js 在大厅尚未安装武将技能时读取已导入包的技能资料，支持皮肤技能语音共享与试听，不向核心注册额外技能。
- 停用原版通过 new Function 重写 useSkill 的旧补丁，保留当前异步技能执行；原版动态玩家钩子仅在旧 decadeUI 和 duilib 渲染器同时存在时运行。
- 大厅播放音效不再依赖 ui.window；修正旧单独音量函数的未定义变量；缺失 CodeMirror 的代码查看插件改用只读文本框，保留复制。
- 不强制开启开发/作弊模式，不清空已有核心皮肤配置。

## 验收与复现

开发服务：核心 Vite `http://127.0.0.1:8184`，文件服务 8089。浏览器使用隔离配置，不修改用户实际游戏存档。

- `pnpm exec tsx --test scripts/skin-system.test.ts scripts/qianhuan-extension.test.mjs`：18 项通过，覆盖核心皮肤服务、资源发现、超时与静态降级。
- 加上 `scripts/extension-organizer/registration.test.ts`，合计 32 项通过。修正其中两处目录重组前的测试资源路径，改走现有扩展路径解析器。
- `node scripts/qianhuan-browser.mjs`：用真实大厅按钮进入原版页面；验证原版卡片换肤/经典还原、DOM 与 PIXI 刷新、双将和隐将入口、暂停恢复、小视口、重载存档、语音资源响应。局内以实际 player 对象初始化曹操/郭嘉，确保主副将都有已交付皮肤可测。
- 手杀大厅场景附带旧核心换肤存档和关闭的旧 precontent 选项，验证迁移与正常初始化；static 场景阻断 8089，验证无文件服务运行。
- 浏览器报告与截图输出到 `output/qianhuan-native/`。`qianhuan-native-browser.mjs` 为同一回归脚本的兼容入口。

本次四个浏览器场景均通过，页面异常数均为 0。1167 个安装文件的清单哈希校验、适配 JS 语法检查、git diff --check 通过；原版文件中修改了 6 个，其余保持 ZIP 原文件。浏览器最终结果见 report.json；本次不生成发布安装包、不提交或推送代码。

## 资源与发布维护

修改程序或添加素材后运行 `node scripts/qianhuan-inventory.mjs`：先重建静态目录索引，再更新 SOURCE.json 中的适配记录与 organized-extensions 的文件哈希。原 ZIP 哈希不变。原图库资源必须随常规构建中的手杀标准 UI 目录共同交付；普通构建的 copyExtensions 会复制这两个目录。

若用户手动禁用了千幻，需要在扩展管理中重新启用并重启。若手动关闭核心换肤，立绘呈现仍遵守核心开关。

## 后续阶段与边界

1. **动态皮肤**：原版代码与配置保留，但当前新核心动态渲染器尚未完成专门适配和验收；本阶段交付静态查看、切换与配音链路。
2. **界面素材**：布局和控件来自原版主题。用户参考图中的特定撑伞小乔、品质标识等取决于实际素材包；不能保证每张图都已有。原版可选高清原画、胜利语音、个别品质图在现有资源中缺失，会出现探测 404 并回退，不代表已提供这些素材。
3. **跨平台与模式**：桌面浏览器普通加载流程已覆盖。独立在线裁剪构建会主动排除普通扩展，不能据此宣称网页在线版已接通；手机安装包、联网同步、回放、变身动态需要单独回归。
4. **完整扩展选项**：原版其他主题、编辑器、可选动态效果均保留，不把主路径验收扩大为全部原版选项验证。

下一阶段优先检查新核心动态皮肤渲染接口与资源清单，再按目标发布平台补测。避免把旧技能执行补丁重新装回核心。
