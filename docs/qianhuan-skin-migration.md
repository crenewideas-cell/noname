# 千幻聆音皮肤功能迁移

## 目标与范围

保留千幻聆音的武将皮肤浏览、大图预览和局内换肤体验，接通手杀、如真似幻大厅与本体人物资料入口。局外选择与局内主副将共享持久化的皮肤选择。删除旧“武将衣橱”页面及其入口、样式、导出和测试依赖；不依赖衣橱，不把旧页面改名充当千幻迁移。

已有本体静态立绘路径解析、配置存储和皮肤数据服务是新核心的基础设施，继续作为适配接口；保留用户保存的皮肤配置。原画目录发现、技能形态 `player.skin`、国战共享规则由核心维护。

## 来源

- 原版主程序：`temp/三国杀·琉璃版5.5/resources/app/extension/千幻聆音/extension.js`。
- 手杀大页面：同目录 `theme/shousha/code/shousha.js`。
- 共享关系：同目录 `skinShare.js`。
- 已迁移素材：`apps/core/extension/ui/手杀标准UI/original/千幻聆音/`。
- 保留原作者说明和素材归属。源码及数据迁移记录写入新模块 `SOURCE.json`。

## 设计

调用方向：大厅/人物资料 → 千幻皮肤页面 → 本体皮肤服务 → 配置持久化 → DOM 与 PIXI 立绘刷新。

页面从千幻手杀主题迁移“经典形象首项、皮肤卡片横向浏览、大立绘、预览与使用状态”的结构与状态逻辑。新增大厅武将索引及搜索。通过明确接口读取武将、列出皮肤、预览和应用；不运行原版扩展入口，不恢复原型覆盖、旧玩家初始化、AI 插件或规则钩子。

素材清单在开发时生成，保留来源哈希与复现脚本；客户端仅读取静态数据，不执行 `skinShare.js` 或皮肤附带脚本。共享皮肤按显式映射解析，不能简单删除所有武将名前缀。静态立绘排除 Spine 图集。缺失图片不写入配置，变身图缺失回退原画。

应用成功后通知页面及大厅纹理加载器。异步请求以代次保护；关闭页面和切换大厅取消后续 UI 更新并释放订阅。局内只刷新既有头像的显示形态，不修改玩家身份、技能、`player.skin` 或事件结果。隐将入口继续遵守核心的可见性判断。

## 阶段与验收

### 阶段 0：删除旧衣橱（源码已完成）

删除两份页面实现、专用 CSS、设置项及公开导出；清理现行调用与回归脚本。历史报告只作为历史证据。旧生成脚本不得重新生成衣橱入口。

### 阶段 1：静态皮肤闭环（已完成浏览器验收）

- 从原版迁移皮肤卡片/选择状态与手杀主题素材，生成真实静态皮肤目录及共享关系。
- 两套大厅皮肤按钮、武将图鉴与局内人物资料接入新页面；包含主副将入口。
- 预览、使用、恢复经典、持久化、DOM/PIXI 即时刷新。
- 验证目录/映射、保存失败、快速切换、关闭后回调、双将/变身不改变规则状态；浏览器验证大厅入口和页面布局。
- 阶段 1 不宣称原版所有主题、皮肤品质/台词详情、动态效果全部复原。

### 阶段 2：千幻详情与配套语音（待开发）

迁移皮肤介绍、品质、台词与试听；梳理共享技能语音映射，将对局语音接入当前核心音频解析。旧千幻配置按可验证规则导入，不能直接执行旧配置脚本。

### 阶段 3：动态皮肤（待开发）

盘点完整骨骼与图集、动作和定位参数；适配动态预览及局内主副将渲染，提供静态回退和设备降级。处理皮肤切换时动态覆盖层与静态底图的一致性。

### 阶段 4：跨环境验收（待开发）

验证离线、联机独立窗口、Electron、Android，检查打包清单和资源传递、重连、切换 UI、窄横屏与触摸。验证只修改本地外观，不广播或修改对局规则。未验证平台明确标注，不能用网页测试替代设备验收。
