# 大厅武将、卡牌与扩展设置修复

## 本次调整

- 笮融的实际武将包 ID 是 `zerongPack`，现归入 PXLNGU；去掉扩展每次启动强行加入武将启用列表的逻辑。
- 武将搜索、扩展搜索及扩展分类内搜索增加“全部状态／已启用／已关闭”。可单独按状态筛选，也可和名称组合；开关改变后刷新结果。工具入口没有启用状态，不混入已关闭结果。
- 搜索定位只滚动右侧内容，避免整张设置页上移、遮挡顶部栏位。
- 新武将包通过 `game.import('character')`、扩展 package 或 `addCharacterPack` 注册时，统一初始化武将页选择；记录来源扩展供分组使用。显式关闭和批量设置持久化，兼容旧扩展自行追加启用列表的情况。
- 已登记但没有主启用标记的手动导入扩展补齐默认开启；已保存的关闭标记不覆盖。
- 武将批量开关覆盖分组内部成员和旧式扩展开关；恢复默认使用副本，避免后续操作污染默认配置。修复联机分组禁将列表未初始化时的访问问题。
- 原“牌堆补充”只有设置和加载名单，执行目录已不存在。现由核心在创建实体牌之前执行，保持原有配置键与设置界面。补牌发生在扩展和模式完成牌堆修改之后。
- 补充按实际已有数量计算缺口，普通杀、火杀、雷杀分别统计；支持全部／一半／不补充、缺省设置和异常数值。不移除原牌，不重复累计；保留单次最多 1000 张的上限。联机模式不在客户端独立补牌。
- 卡牌注册时统一转换火杀、雷杀、冰杀等旧 ID，修复扩展内容晚于启动转换阶段、导致编辑添加的属性杀不进入实体牌堆的问题。保存的编辑数据保持原样。
- 删除自定义牌堆时同时处理全局与各模式的牌堆引用。

## 实时开关与头像边缘修复

- 增加串行的扩展实时加载入口，执行导入、准备、武将／卡牌注册和内容加载，补齐启动后已消费的生命周期队列。正在加载时防止重复提交；加载失败显示原因、复原开关并允许重试。
- 已成功加载的扩展反复开关不会重复执行工厂或内容，不重复注册技能。父扩展开关同步武将可用状态，保留用户主动关闭的子武将包。
- 实时补齐扩展自身设置项；武将栏位、搜索结果、启用状态及已打开的武将清单同步刷新。
- 手杀武将框原先将带有内缩图案的选将素材作 `border-image` 切片，形成偏移描边、顶边细线和角部暗块。移除该层图片，保留原有宽高、间距、3px 透明占位和投影；立绘按外框裁剪且不平铺。选中高亮的尺寸及圆角与外框一致，不裁掉体力标记。
- 浏览器逐项验证 8 个扩展在同一文档中从关闭状态开启并显示武将；验证武将页预先打开后的同步、父扩展开关循环、保留子包选择、注入网络失败后重试，以及晚注册的包。页面错误为 0。
- 手杀界面抽查三张已加载立绘的四个外角，像素均为大厅底色与正常投影的混合，没有纯黑角块；同时检查 `border-image:none`、背景外框裁剪和不平铺，并保留截图 `output/extension-character-audit/portrait-1.png` 至 `portrait-3.png`。
- 相关逻辑测试 50 项通过；新增 `extensionRuntime.ts` 单独类型检查通过。全库 TypeScript 检查仍报告大量错误，输出保存在 `output/extension-live-typecheck.txt`，未将其记为通过。

本次修改为源码修复，未重新打包 EXE/APK。浏览器验证使用独立测试存储，不改用户存档。开关影响下一次加载，修改后重新进入游戏或重启生效。以上验证覆盖配置与加载链路，不代表穷举所有第三方武将技能组合。
