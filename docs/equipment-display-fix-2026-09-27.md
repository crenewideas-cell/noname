# 本人装备区显示修复

## 复现与原因

在手杀标准 UI 的移动布局中，开启 `textequip`（文字装备）并通过引擎装备接口放入诸葛连弩、八卦阵、的卢、赤兔、木牛流马。本人装备容器及五张装备行的实际高度均为 0，名称叠到头像底部之外；相同装备在其他玩家处正常。关闭文字装备后行高恢复。

`layout/mobile/equip.css` 对本人文字装备设置 `height:20%!important`，其选择器优先级超过手杀展示层的 `height:22px!important`。手杀的装备容器又是自动高度，百分比行高因此不能撑开容器。十周年展示层已有最小行高，但仍需要统一处理百分比高度与非文字装备的整卡图层。

## 修复

`layout/default/equipment-labels.css` 由默认布局导入，仅在手杀或十周年的武将展示组件启用时生效：

- 明确装备行的实际高度和最小高度，统一盒模型，覆盖本人的百分比高度规则。
- 使用引擎的 `.name2` 装备名称，收起整卡插图、点数等非紧凑展示图层。
- 限制装备堆叠区域，统一文字行高与深色底；保留主题颜色差异及选中高亮。
- 不替换装备节点、不改装备归属、触发器、出牌逻辑或原生布局。

## 验证方式

`NONAME_UI_TEST_ORIGIN=http://127.0.0.1:8081 node scripts/equipment-display-browser.mjs` 在独立浏览器配置中启动实际引擎，通过 `addVirtualEquip` / `directequip`、移除接口和实际展示组件验证：本人及对手、文字装备开/关、替换武器、移除防具、960×540 缩放窗口、十周年组件。检查行高、文字边界、不重叠、鼠标命中及选中高亮，截图保存在 `output/equipment-display/`。

测试使用引擎接口构造局内装备状态，不连接真实房间；不等同于覆盖所有扩展技能及完整联机出牌流程。
