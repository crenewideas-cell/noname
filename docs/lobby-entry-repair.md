# 大厅珍宝阁、武将和皮肤入口纠正

## 原因

之前迁移时，把旧 `skinSwitch.cangZhenGe()` 改成了通用 `bridge.collection()`；如真似幻的 `lobby_czg` 也被改成了 `lifecycle.skins()`。随后皮肤入口又被统一指向武将目录，导致独立抽奖系统误入武将页。两个地方都是适配层接错，不是千幻的原版设计。

千幻提供的是「按武将组织的资料与皮肤详情」，包括皮肤列表、预览、默认皮肤、配音、选项和局内换肤。它接管详情页，并不等于只提供大厅已有的武将目录。原版没有独立的全部武将皮肤商城，因此不能以“还原千幻”为名另画一个商城。

## 修复后的入口

| 大厅入口 | 行为 | 页面来源 |
| --- | --- | --- |
| 武将 | 打开当前大厅已有目录；点击武将进入其资料页，遵守原列表默认页设置 | 两套大厅原目录 + 千幻原详情 |
| 皮肤 | 直接打开最近查看武将的千幻皮肤页；原版返回按钮回到已有目录，选人继续进入皮肤页 | 原版 `qhly_open(name, 'skin')`，不增加选将按钮 |
| 珍宝阁（源码/素材名称：藏珍阁） | 独立打开礼盒抽奖，包含奖池切换、奖励预览、单抽、批量抽取、奖励动画和统计 | 项目原有「皮肤切换」的 `cangZhenGe` 及素材 |

手杀大厅 `under5`、`under6`、`czg` 分别接皮肤、武将、抽奖。如真似幻 `pifubutton`、`wujiangbutton`、`cangzhengebutton → lobby_czg` 做相同区分。

皮肤页下面的卡片浏览当前武将全部已安装、可识别的皮肤。保留原版拖动/触摸滑动，并为原有左右箭头补齐点击翻动（上游只有指示图案，未绑定点击）。跨武将使用现有目录，关闭资料时只有收藏发生变化才刷新收藏列表，普通浏览不重置目录位置。原版预览和“设为默认”语义保留。

梦之回廊是另一个扩展入口，不能拿皮肤页替代。本项目没有安装其业务程序，当前使用大厅已有提示说明依赖缺失，不新增页面。

## 珍宝阁来源和兼容边界

原代码来自项目 `temp/三国杀·琉璃版5.5/resources/app/extension/皮肤切换/`；单独提取 `cangZhenGe`、`czg_setting.js` 和随包 pixi-ease。新代码位置为 `apps/core/noname/ui/treasure/`，`SOURCE.json` 记录原始文件 SHA-256。

全部图像、样式、音效与 Spine 素材复用 `apps/core/extension/ui/手杀标准UI/original/皮肤切换/`，没有生成、绘制或下载新的页面素材。保留原版 61 个礼盒配置、概率权重和保底规则。原程序为本地抽奖模拟：礼盒初始数量和本次统计沿用原逻辑，不新增收费、商城库存、武将解锁或皮肤发奖关系。

适配仅处理当前核心要求：

- 原来未启动的第二批奖励动画资源加载补齐，资源就绪后才允许抽奖/预览。
- 原程序退出时删除 `ui.window/ui.arena` 的行为移除；退出只清理自身节点、PIXI 应用、音频、补间与定时器。
- 音频路径改为当前核心支持的 `ext:`；PIXI 工厂调用适配当前版本。
- 少数上游奖品配置指向缺失图标：优先使用同编号已有武将图标；仍缺失时保留原框、名称和数量，不臆造图片或修改中奖规则。
- 源码提取脚本同步保留这些修正，两套大厅的迁移脚本也使用独立路由，避免重新生成后复发。

重新提取：`node scripts/restore-treasure.mjs "temp/三国杀·琉璃版5.5/resources/app/extension/皮肤切换"`。

## 回归验证

`node scripts/lobby-entry-regression.mjs rzsh shousha` 通过实际大厅点击检查：三个入口不串页、原版返回后连续换将、皮肤左右翻动和选择、最近武将恢复、礼盒选择、奖励预览、单抽、50 连抽、累计统计、动画未结束时关闭及退出重开、皮肤存档未被抽奖修改、核心窗口未被删除。报告和真实截图位于 `output/lobby-entries/`。

千幻原有换肤、简介、配音、存档和局内入口另由 `scripts/qianhuan-browser.mjs` 回归。全功能迁移尚未验收的动态与外部插件项目仍以 `qianhuan-feature-audit.md` 为准，本次入口修正不将它们标为完成。

## 失效的最近武将记录

大厅皮肤入口不指定武将时，`qhly_lastCharacter` 可能指向当前没有加载的扩展武将，例如 `hlhj_daiyu`。此前直接对这个历史记录抛出异常，导致点击手杀大厅皮肤按钮弹出源码错误。

现在只在无明确武将参数时校验并回退：有效的最近武将、曹操、当前已加载的公开武将。成功打开原千幻页面后才更新最近记录，不加载或启用额外武将包，也不改变皮肤选择。正常的常用入口不遍历全目录。

明确指定的武将缺失，或当前没有可查看武将时，复用已有的可关闭提示框；不冒充另一名武将，不破坏已打开的资料会话。`scripts/qianhuan-entry.test.mjs` 覆盖失效记录、有效记录、显式缺失、空目录及恢复重试；`scripts/qianhuan-stale-entry-browser.mjs` 实际点击两套大厅的皮肤入口并验证重开及刷新后的记录。
