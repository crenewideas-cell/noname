# UI 工坊：套装、混搭与素材分享

## 入口与操作

入口位于 **大厅 → UI 工坊**，也可以通过 **选项 → 外观 → UI 工坊** 打开，桌面键盘快捷键为 **Ctrl + Shift + U**。游戏原有外观设置继续保留。

1. 从当前游戏外观创建搭配，或在套装库中选择“内置 · 墨金 / 霁蓝 / 青玉”后载入整套。
2. 选择左侧部件，在“从其他套装选取这个部件”中选取来源。也可以添加自己的图片、字体，调整颜色、圆角、间距和其他外观属性。
3. 保存搭配，或另存为独立套装。保存本身不改变当前游戏画面。
4. 点击“应用并返回大厅”，保存完成后重新载入大厅。进入房间、匹配中或对局中需要先退出，工坊仍允许编辑、保存和导出。
5. 用“导出当前搭配”导出 ZIP；其他玩家用“导入套装 ZIP”导入，载入整套后应用，或只选其中的部件。

套装库中的“载入整套”只替换编辑草稿，不立即应用。导入也只加入套装库，不丢弃当前草稿。名称相同的套装可以并存；ID 冲突时导入为独立副本。内置套装编辑后保存、导出会使用新 ID。

“恢复原有外观”停用工坊覆盖；“撤销上次应用”返回上一次套装（也可返回未使用套装的状态）。使用中和用于撤销的套装禁止删除，避免断开引用。修改这两类套装会保存新副本。

## 可以管理的内容

| 部件 | 原有配置与自定义素材 |
| --- | --- |
| 主界面 / 启动入口 | 经典、手杀入口模板；背景、配色、排版 |
| 模式选择 | 启动页样式一 / 二；按模式 ID 替换封面；卡片间距和布局 |
| 联机大厅 / 房间 | 背景、颜色、控件内部的外观规则 |
| 对局背景 / 布局 | 本体主题、布局、触屏布局、背景与模糊；自定义背景 |
| 卡牌正面 | 本体样式、通用底纹、按卡牌 ID 的图片 |
| 卡牌背面 | 本体卡背、自定义背面与未翻转背面 |
| 按钮 / 操作控件 | 本体控件样式、自定义纹理、颜色、边框、圆角 |
| 菜单 / 弹窗 | 本体菜单样式、圆角、背景纹理、排版 |
| 武将框 / 选将外观 | 本体角色样式、边框、经典 / 手杀武将界面；背景与边框图片 |
| 体力图标 | 本体样式；高、中、低、已损失体力四类图片 |
| 攻击 / 拖拽指示线 | 本体指示特效；默认线的颜色、宽度、透明度、发光和纹理 |
| 界面字体 | 本体各类字体配置；导入自定义界面字体 |

卡牌和模式支持批量添加，使用文件名作为 ID，例如 `sha.png`、`shan.webp`、`identity.jpg`、`guozhan.jpg`。不使用武将/卡牌的显示中文名替代内部 ID。

图片支持 PNG、JPG/JPEG、WebP、GIF、AVIF；字体支持 WOFF、WOFF2、TTF、OTF。每套最多 512 个被引用素材、总计 128 MiB。替换或移除后未使用的素材不会进入保存和导出结果。

预览是独立的样式与素材示意，不执行模式、技能或联机代码。本体主题、布局和入口模板以应用后的实际画面为准。导出的 GIF 可用作动态背景/纹理；现有画布型攻击动画由本体特效选项控制，不会自动把任意动画脚本转换为素材。

## 与无名杀扩展格式的关系

导出采用本工程现有的 **ESM 扩展 ZIP 格式**，与本工程 1.11.6 的扩展导入器、扩展制作器保持相同入口约定：

```text
我的搭配-UI套装.zip
├── extension.js        # import from "noname"、type="extension"、default 导出
├── info.json           # name、translation、author、intro、version
├── ui-workshop.json    # 部件与素材清单
├── README.txt
└── assets/
    ├── ui-<唯一标识>.png
    └── ui-<唯一标识>.woff2
```

ZIP 根目录就是这些文件，不要再套一层文件夹。扩展安装目录为 `extension/UI套装_<ID>/`。显示名称与 ID 分离，中文显示名称可以自由修改。

**两条导入路径：**

- **UI 工坊导入**：读取并校验清单和素材，存入游戏已有 IndexedDB；不执行压缩包中的 `extension.js`。纯网页环境无需文件系统权限也能保存 UI 套装。
- **原有扩展入口导入**：沿用 `game.importExtension`，安装为常规扩展，受原有文件系统权限限制。启用后自动登记到工坊套装库；在工坊中应用，或点击扩展设置的“使用此 UI 套装”。

导出包自带样式渲染器。在**支持相同 ESM 扩展入口但没有工坊的客户端**，可以作为外观扩展加载，多个套装通过各自扩展设置的“使用此 UI 套装”选择。完整的按部件混搭需要安装此版工坊。关闭所选扩展并重启后不再加载该包的外观覆盖。

**兼容边界：**

- 不支持仅接受旧式 `game.import(...)` 脚本、没有 ESM 导入映射的旧版加载器。
- 主界面、联机大厅、模式卡片的结构在不同分支可能不同；对应选择器需要该客户端具有相同页面结构。本工程的专有大厅不能仅通过几张素材在其他分支中生成出来。
- 本体内置主题、字体、布局和攻击动画使用接收方本体资源；自定义图片和字体随 ZIP 携带。接收方需要具备选用的本体功能。
- 旧“十周年 UI”“手杀 UI”等扩展若没有 `ui-workshop.json`，继续通过原有扩展入口安装。工坊不会分析并执行它们的 JavaScript 来推测可拆分部件；可手动加入其独立图片，或由扩展作者提供清单。其他扩展直接覆盖 DOM/CSS 时仍可能产生样式冲突。
- 联机仍遵循已有菜单和规则约束。工坊不更改服务器协议、身份、技能、卡牌规则或可见信息；对隐藏卡牌的正面不会应用自定义卡面。

## 素材与持久化

素材在 IndexedDB 的既有 `data` store 中以 `ui-workshop:<ID>` 保存，索引及当前/上一次选用 ID 保存在既有 `config` store。套装数据和索引在同一个事务提交，避免出现“库里有套装但素材未写入”的半成品；选择记录也原子提交。

每次混搭复制素材字节，组合后的套装不依赖来源套装、文件选择器地址或开发电脑路径。导出只含清单、已引用素材和固定加载器，不包含账号、联机凭据、存档、武将技能或其他扩展代码。

套装配置在启动时覆盖内存配置，不批量改写原有外观偏好。加载失败回退本体外观并在工坊显示错误。URL 加上 `?uiSafe=1`（已有查询参数时用 `&uiSafe=1`）可以本次启动跳过套装，进入工坊恢复原有外观。

## 作者清单规范

格式名称为 `noname-ui-workshop`，版本为 `1`。可只提供部分部件；没有指定的设置沿用玩家原有配置。

```json
{
  "format": "noname-ui-workshop",
  "version": 1,
  "id": "my-blue-theme",
  "name": "我的蓝色主题",
  "author": "作者",
  "description": "按钮与指示线组合",
  "components": {
    "buttons": {
      "name": "蓝色按钮",
      "settings": { "control_style": "default" },
      "assets": { "texture": "assets/button.png" },
      "style": { "color": "#e6f3ff", "border-radius": "10px" }
    },
    "lines": {
      "name": "蓝色指示线",
      "settings": { "zhishixian": "default" },
      "assets": {},
      "style": { "color": "#80caff", "width": "4px", "opacity": "0.9" }
    }
  }
}
```

部件 ID、可用配置键、素材位置和外观属性见 `apps/core/noname/ui/workshop/schema.js`。图片与字体路径只能为 `assets/<字母数字下划线或短横线>.<支持的扩展名>`，不能使用绝对路径、网络地址、父目录或脚本文件。

按对象替换的素材使用 `cards.assets["card:sha"]`、`modes.assets["mode:identity"]`。通用素材位置包括 `background`、`texture`、`frame` 等，以对应部件声明为准。

高级清单中的 `rules` 是作用于该部件内部元素的规则列表，例如：

```json
{
  "selector": ".lobby-mode-caption",
  "style": { "color": "#ffffff", "padding": "12px" }
}
```

一个规则使用一个相对选择器；需要多个目标时写多条规则。样式只接受声明的外观属性，禁止脚本、外部 `url()`、`@import` 和规则块插入。图片通过 `assets` 绑定。工坊界面使用独立 Shadow DOM，预览使用不允许脚本的 iframe，避免套装样式污染管理入口。

代码扩展可在 `precontent` 中调用 `lib.uiWorkshop.registerExtension(manifest, extensionName)` 登记；工坊会通过游戏现有文件 API 读取扩展目录的素材，没有文件 API 时使用同源资源地址。重新导入更新包可创建独立副本，不自动覆盖玩家已编辑的套装。
