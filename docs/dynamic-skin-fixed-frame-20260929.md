# 固定皮肤画框与独立背景取景

2026-09-29。本机公共播放器版本 `e7c15c065f85e5bdc43b`，缩略图缓存版本 `fixed-frame-v1`。

预览和局内头像不再把内容宽高比写回外框尺寸，也不再读取旧的自适应尺寸缓存。边框由原主题布局决定；窗口自身的响应式布局仍由主题管理。人物、背景和特效只在既定画框内显示。

数字命名的骨骼可能只提供躯干点，没有可识别的人脸。原背景采样把该点按人脸的高度区间验证，拒绝了有效底图；后续整图容纳又使人物缩小，并通过 `previewAspect` 改变边框。现在明确区分躯干点和人脸。对于没有既有配准、完整模型替换、显式构图或源场景配置的 4.0 双层素材，若能测得不透明背景，则使用固定的人物待机纵向边界取景，独立背景等比铺满画框。无有效背景证据的素材继续原有策略。没有按武将或皮肤 ID 设置生产参数，没有修改源骨骼、纹理和目录条目。

实际游戏千幻页面核验郭嘉“以身证道”“破晓逐辰”、司马懿“狼顾鬼才”：三者的画框位置和尺寸相同，动态与静态切换时主题外框均保持 448×670 逻辑尺寸。核对实际 iframe 使用上述公共版本；“以身证道”出场后正常返回待机，两个数字命名样例的人物与背景在固定框内显示。截图包含 1440×900、1280×720、1920×1080 页面。
