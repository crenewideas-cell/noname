# R10：查看性能与出场衔接

2026-09-27。正式公共播放器 `22b2648aa71c7718dc3e`，四包仍共用同一份代码。机器记录与画面对照位于 `output/dynamic-remediation/20260926-r01/performance-r10/`。本轮未启动对局，按用户要求由用户测试对局。

## 修复

- 千幻手杀查看界面原来在打开页面、每次换肤时同步 HEAD 检查国战原画及胜利语音。CPU 采样追到 `thunderFileExist → XMLHttpRequest.send`，一次回切出现 4177 毫秒主线程任务。改为异步、限时、最多 256 项复用；过期选择的响应不能更新当前按钮。
- 缩略图缓存读取不再排在模型渲染队列后；一个后台生成器向选中预览让出资源。不可见任务取消，可见失败任务重试，数据库不可用也能生成图片。预览首帧直接缩成 WebP，不再先编码整幅 PNG。
- 缩略图使用构图版本 `camera-r09-v1`，并兼容读取 R09 的旧缓存。代码升级不会让所有已生成原画失效；后续改变待机取景必须升级此版本。
- 公共资源缓存合并原生 Spine 加载器的输入字节与图片解码，保留独立骨骼状态和 GPU 纹理。字节缓存 24 MiB，图片缓存 96 MiB，45 秒过期。PIXI/Live2D 未改为共享骨骼或纹理，不宣称所有格式具有同样的加载收益。
- 快速换肤延迟 100 毫秒创建新播放器，取消被跳过的选择；同一预览节点保留最近三个播放器，其中非当前播放器暂停，45 秒过期，页面关闭时释放。原生 Spine 与已有 PIXI 一样限制为 30 FPS。
- 出场预览原来使用对局右侧锚点，且与待机使用不同相机。现在先采用预览中央锚点，再按出场落定的人脸或同源附件几何，对齐待机位置、比例。匿名数字骨骼通过附件对应关系配准；对应不足或残差过大时不强行匹配。不按皮肤 ID 设置偏移。
- 已对齐出场的主体在片尾完全透明时，及时恢复待机主体，同时允许剩余特效结束，避免黄盖片尾短暂只剩背景。

## 边界与保留

首次访问的大型骨骼解析、图像解码仍可能耗时并产生长任务；已有缓存的原画和最近预览可以复用。本轮没有实现全库预生成，也不承诺所有 4934 条、所有机器永久零卡顿。对局点击、自动事件及耐久不标为本轮实测通过。

R09 记录的大乔绮裙轻袖原素材缺脚、黄月英万圣节源切边仍未修复。冻结 4934、优先 4895、暂缓 39、删除 0、逐条最终验收 0 不变。没有改写源素材、catalog、正式存档或清理其他任务改动。

旧 a5 正在使用的兼容文件原位保留。本轮不可变中间 release 作为过渡归档保留，正式指针仅指向 `22b2648aa71c7718dc3e`。精确回退说明见同证据目录 `rollback/README.md`，不是删除目录或 reset/clean。
