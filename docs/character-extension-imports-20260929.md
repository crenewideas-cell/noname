## 使用位置

在游戏的“扩展 → 合并扩展包 → 清瑶葭绮”中开启，武将列表中进入“假装无敌”，或搜索“少女清瑶”。沿用原扩展开关和存档；不会另建同名扩展。已开启的开发版刷新或重启后加载新版。

“假装无敌”从 56 增至 **57 个武将定义**，“清瑶葭绮”合并包从 74 增至 **75 个定义**；菜单显示 69 个可见条目，其余为隐藏形态。新增 `qy_qyshaonvqingyao`，保留全部旧 ID。少女清瑶带有源包的 `forbidai` 标记，正常随机 AI 选将不选用她，可手动选择。

## 整合内容

- 新增少女清瑶、泣玉／顾梦／纠音／浮曦／望遥及子技能、翻译、称号、六维信息、立绘、阵亡与技能语音。

- 从 ZIP 补入 22 个文件，更新 59 张原有立绘，跳过 90 个内容相同的文件；小游戏的脚本、背景、按钮和音效均来自 ZIP。工程自制卡图继续使用原路径。
- 当前本体没有十大神器，因此从本地保留的 `temp/三国杀·琉璃版5.5/resources/app/card/swd.js` 提取十张所需装备及 14 个关联技能，并补入对应原图。仅作少女清瑶的衍生资源，不向普通牌堆添加卡牌。
- 武将代码、必要依赖及新素材加入 Git 白名单，并更新安装登记与文件哈希。

武将入口仍使用现有的模块工厂。原完整包的全局界面、缩放、引擎覆盖代码及独立 BOSS 挑战场景没有进入活动加载路径；本次整合范围是武将包及其必要依赖。正常模式下少女清瑶的技能链可使用。
